# mathieutellene.github.io

Personal site of Mathieu Tellene: case studies of the automation, data and AI systems I build for operations teams.

Live at https://mathieutellene.github.io

## What is here

| Path | Content |
|---|---|
| `index.html` | Home: projects, testimonials, experience, skills, courses, writing, contact |
| `work/*.html` | Fifteen case studies: AQM, DQM, WhatsApp ride-booking agent, email-to-reservation pipeline (B2B), CabiBot, ADP, RPA Uploader, COPs Control, LLM cost control, hybrid ML + LLM vision engine, forecasting, events intelligence, local AI agent, personal AI chief of staff, Smart Fleet Manager (hackathon) |
| `Mathieu_Tellene_CV.pdf` | One-page CV |
| `Mathieu_Tellene_n8n_Dossier.pdf` | n8n workflow dossier: diagrams drawn from real exports, relabelled in English |
| `Agent_Builders_Field_Manual.pdf` | The Agent Builder's Field Manual, a personal reference on building agent systems |
| `assets/` | CSS, JavaScript, self-hosted fonts, tool logos, screenshots, thumbnails, diagrams |

Plain static HTML, CSS and a little JavaScript (theme toggle, filters, counters, lightbox). No build step on the server, no tracking, no external requests: fonts and logos are self-hosted, and charts and diagrams are inline SVG.

## About the screenshots

The screenshots of internal tools show the real interfaces rendered with synthetic data. Client, supplier and people names, internal hosts, credentials and business figures are left out on purpose. The numbers on the site describe my own automations, not the company's business.
