# Portfolio · Mathieu Tellene

Personal site of Mathieu Tellene: case studies of the automation, data and AI systems I build for operations teams.

Live at https://mathieutellene.github.io/

## What is here

| Path | Content |
|---|---|
| `index.html` | Home: projects, experience, skills, courses, writing, contact |
| `work/*.html` | Ten case studies (vision AI fleet audit, WhatsApp and Help Center agents, hybrid ML + LLM vision, KPI monitoring, change requests as rules, an emergency shared-van service built in 48 hours, forecasting, events intelligence, a hackathon build) and one technical note on LLM agent cost |
| `Mathieu_Tellene_CV.pdf` | One-page CV |
| `assets/` | CSS, JavaScript, self-hosted fonts, tool logos, illustrations, certificates |

Plain static HTML, CSS and a little JavaScript (theme toggle, filters, counters, lightbox). No build step on the server, no tracking, no external requests: fonts and logos are self-hosted, and charts and diagrams are inline SVG.

## About the content

The case studies describe my own work at a high level: the problem, the approach, the result and what I learned. They contain no confidential information, screenshots, code or internal figures from any employer. Diagrams and charts are illustrative and drawn from scratch, example data is invented and numbers are rounded.
